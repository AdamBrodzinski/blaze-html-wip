# Blaze templates

The Blaze template is a serverside html templating engine that uses a templating language
that has a similar syntax to web components. This allows the user to use any html formatting
and syntax highlighting.

The templating engine is instantiated and the instance is called to render the page.


### Future Usage Example
```rust
let blaze = BlazeTemplate::new()
    .register_components_directory("src/components")
    .register_layouts_directory("src/layouts")
    .register_pages_directory("src/pages")
    .panic_on_error(true); // used when testing in CI

let data = json!({"title": "Home"});

let html = ctx.blaze
    .render_page(data, "customers/view.html");

Html(html) // return html in axum
```
