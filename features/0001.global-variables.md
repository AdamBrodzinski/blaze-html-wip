# Variable Replacement Feature

The first feature of the template language is variable replacement. The variable
syntax starts with @@ followed by alphanumeric characters or an underscore. The
key can contain a `.` character to use nested data (ex: `@@person.items.phone`)

Example:

## Template processed with the data {"name": "Jane"}

```template
Hello @@name !
```

```output
Hello Jane !
```

## Acceptance Criteria
- should replace variables by json key name
- should handle nested json keys, foo.bar

## Examples
```rust
let data = json!({"name": "Jane", "age": "45"});
let tmpl = "name: @@name, age: @@age";
let result = replace_variables(tmpl, &data);
assert_eq!(result, "name: Jane, age: 45");
```
