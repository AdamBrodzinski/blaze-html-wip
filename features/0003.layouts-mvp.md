# Layouts MVP Feature

The templates needs to handle the use case of 'layouts' in order
to wrap boilerplate html around a 'page'.

### Requirements

- layout element takes a path attribute with a filepath relative to src
- can consume global variables in layout

### Non goals

- nested layouts can be ignored
- data does not need to be passed into a layout


### Example
- template that uses a layout
  ```html
  <layout path="layouts/admin.html"><h1>Posts</h1></layout>
  ```
- layout contents
  ```html
  <html>@CONTENT</html>
  ```
- final output
  ```html
  <html><h1>Posts</h1></html>
  ```
- API using layout
  ```rust
  let tmpl = "<layout path='layouts/admin.html'><h1>Posts</h1></layout>";
  let layout = "<html>@CONTENT</html>";
  let data = json!({"title": "MyApp - Home"});
  let result = render_template_str_with_layout(tmp, layout, data);
  ```
