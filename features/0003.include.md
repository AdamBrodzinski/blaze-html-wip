# Include MVP Feature

Templates need to include text from files in the project. The include tag will
load the text from a file and replace the tag with it's contents. The path tag
is relative from the location that the program is executed in.


Layout template:
```html
<div>
  <h1>Foo</h1>
  <style>
    <UnsafelyInclude path="src/pages/home.html" />
  </style>
</div>
```
