# Include MVP Feature

Templates need to include text from files in the project. The include tag will
load the text from a file and replace the tag with it's contents. The path tag
is relative from the location that the program is executed in.


Layout template:
```html
<div>
  <h1>Foo</h1>
  <style>
    <UnsafelyInclude path="src/pages/home.html" />
  </style>
</div>
```


Consider a nested template:
<Each items="@groups" as="group">
  @group.name
  <Each items="@group.items" as="item">
    @group.name  <!-- Still need outer "group" here! -->
    @item.name
    @i           <!-- Inner index -->
  </Each>
</Each>

The inner loop needs access to:
1. item - current inner item
2. i - current inner index
3. group - outer loop's item (not just root data)
4. Root data for any non-loop variables
